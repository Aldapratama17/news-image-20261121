# One Day, One World

An AI-authored infographic that sums up Saturday 21 November 2026's world news in one image — built for [make.fun's news-image-20261121 bounty](https://make.fun/bounty/news-image-20261121?utm_source=github&utm_medium=readme&utm_campaign=news-image-20261121).

`draw.py` renders the image with Pillow; `main.ts` copies `entry.png` to `/output/entry.png` deterministically.

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
